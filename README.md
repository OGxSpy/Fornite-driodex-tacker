# 🤖 Fortnite Droidex Tracker
A droid collection tracker for **Star Wars: Droid Tycoon** (Fortnite Creative).

## Features
- Track all 56 droids across 5 rarities (Common → Iconic)
- 6 variants per droid: Base, Gold, Diamond, Rainbow, Beskar, Galactic
- AI screenshot scanning (requires OpenAI API key)
- Search & filter by rarity, type, and collection status
- Progress bars per rarity
- Data saved in your browser automatically

## Usage
Just open `droidex_tracker.html` in any browser — no install needed!
